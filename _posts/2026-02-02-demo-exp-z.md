Welcome to the live demo of **Exp-Z**.

I designed and built this application to track personal expenses efficiently.
It runs entirely on the client-side, meaning it's fast, private, and doesn't require a backend server.

## The Tech Stack

I chose a modern, lightweight stack to ensure high performance and maintainability:

+ **Core:** React
+ **Build Tool:** Vite
+ **Styling:** Tailwind CSS
